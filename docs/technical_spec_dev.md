# Технічне завдання
## MIL-комплекс: адаптивний MPC на функціонально розподіленій ядерній моделі (SVR/KRR/GP)

**Стек:** Python (numpy, scipy, scikit-learn, cvxpy)
**Тип:** дослідницький верифікаційний код, Model-in-the-Loop
**Версія ТЗ:** 1.0

---

## 1. ЗАГАЛЬНИЙ ОПИС

Розробити програмний комплекс, що реалізує замкнений контур «модель об'єкта ↔ адаптивний MPC-регулятор» та проводить серію експериментів із порівнянням до базових ліній.

Регулятор поєднує три ядерні моделі:
- **SVR** — фільтр аномальних спостережень перед навчальною вибіркою;
- **KRR** — номінальна прогнозна модель;
- **GP** — оцінка апостеріорної дисперсії прогнозу.

Апостеріорна дисперсія GP керує трирівневою адаптацією штрафної матриці `R(k)` у задачі оптимізації MPC. KRR і GP використовують **спільну** матрицю Грама.

Об'єкт керування — модель процесу мокрої магнітної сепарації.

**Вимоги до якості коду:** модульність, повне покриття тестами, повна відтворюваність результатів, трасування кожного числового параметра до конфігураційного файлу.

## 2. МОДЕЛЬ ОБ'ЄКТА КЕРУВАННЯ

### 2.1. Змінні

Об'єкт — магнітний сепаратор ПБМ 90/250 з прямотечійною ванною. **Єдине джерело істини щодо діапазонів керуючих впливів — `object_spec_PBM_90_250.md`** (значення за ГОСТ 10512-78). Наведені нижче діапазони мають збігатися з ним; у разі розбіжності пріоритет має специфікація об'єкта.

| Категорія | Змінна | Позначення | Діапазон | Джерело діапазону |
|-----------|--------|-----------|----------|-------------------|
| Керуючий вплив | Магнітна індукція | B | 0,065–0,160 Тл | ГОСТ 10512-78, Табл. 1 |
| Керуючий вплив | Густина пульпи | ρ | 1500–1550 кг/м³ | ГОСТ 10512-78, Табл. 3 (прямотечійна ванна) |
| Керуючий вплив | Продуктивність живлення | Q | 105–160 т/год | ГОСТ 10512-78, Табл. 1 |
| Вихід | Масова частка заліза в концентраті | βFe | орієнтовно 63–66 % у номіналі | `static_model_spec.md`, розд. 9.2 |
| Вихід | Витяг заліза | ε | орієнтовно 90–95 % у номіналі | `static_model_spec.md`, розд. 9.2 |
| Збурення | Масова частка заліза у живленні | αFe | 28–38 % | орієнтовно, криворізькі магнетитові кварцити; точне джерело — відкрите питання |
| Збурення | Гранулометричний склад живлення | d | параметр розподілу | — |

**Примітки:**
- Діапазони `B`, `Q`, `ρ` — нормативні (ГОСТ), не «орієнтовні»; розробник не змінює їх довільно. Діапазон `ρ` вузький (50 кг/м³) — це властивість об'єкта за ГОСТ, врахувати при налаштуванні обмежень QP.
- Діапазони виходів `βFe`, `ε` — орієнтири правдоподібності, не еталони; модель феноменологічна, див. `static_model_spec.md`.
- Діапазон `αFe` — поки що орієнтовний; це зафіксоване відкрите питання, не «заглушка для уточнення».

### 3.2. Специфікація модулів ядерної моделі

#### 3.2.1. `gram_matrix.py`

| № | Вимога |
|---|--------|
| 1 | Обчислює `(K+λI)⁻¹` один раз за крок `k` |
| 2 | Надає результат одночасно модулям KRR і GP |
| 3 | Лічильник операцій інверсії та вимірювання часу обчислення (для порівняння зі схемою двох окремих інверсій) |

#### 3.2.2. `svr_filter.py`

| № | Вимога |
|---|--------|
| 1 | SVR з ε-нечутливою функцією втрат і RBF-ядром |
| 2 | Класифікація спостереження як аномального за критерієм перевищення ε-трубки |
| 3 | Вихід: бінарне рішення (норма/аномалія) + відстань до трубки |
| 4 | Параметри `ε, C, γ_SVR` — конфігуровані; метод вибору (крос-валідація) реалізований і задокументований |
| 5 | Журналювання: рішення фільтра та його причина на кожному кроці |

#### 3.2.3. `krr_model.py`

| № | Вимога |
|---|--------|
| 1 | Kernel Ridge Regression з RBF-ядром |
| 2 | Навчання на ковзному вікні (розмір конфігурований) |
| 3 | Формує номінальний прогноз вектора виходу на горизонті `Np` |
| 4 | Регуляризатор `λ` — спільний з GP-модулем |
| 5 | Використовує матрицю Грама з `gram_matrix.py`, не перераховує самостійно |

#### 3.2.4. `gp_supervisor.py`

| № | Вимога |
|---|--------|
| 1 | GP-регресія з RBF-ядром, узгодженим з KRR |
| 2 | Обчислює апостеріорну дисперсію `σ²_GP(ξ(k))` для регресорного вектора `ξ(k)` (регресор містить стан, керування і лаги) |
| 3 | Дисперсія обчислюється на горизонті `Np` |
| 4 | Використовує ту саму матрицю Грама `(K+λI)⁻¹`, що й KRR |
| 5 | Журналювання `σ²_GP` на кожному кроці |

#### 3.2.5. `r_adaptation.py`

| № | Вимога |
|---|--------|
| 1 | Трирівнева логіка: штатний (`σ²_GP < θ₁`), обережний (`θ₁ ≤ σ²_GP < θ₂`), консервативний (`σ²_GP ≥ θ₂`) |
| 2 | Кусково-визначена `R(k)`: штатний `R₀`; обережний `R₀ + α·σ²_GP·I`; консервативний `γ·R₀` |
| 3 | Пороги `θ₁, θ₂` — конфігуровані; метод визначення задокументований |
| 4 | Гістерезис переходів між режимами — реалізувати як вмикувану опцію |
| 5 | Журналювання: режим, значення `R(k)`, причина переходу на кожному кроці |

#### 3.2.6. `qp_solver.py`

| № | Вимога |
|---|--------|
| 1 | Формує і розв'язує QP-задачу MPC з поточною `R(k)` |
| 2 | Враховує обмеження на керування та на приріст керування `|Δu| ≤ Δu_max` |
| 3 | Реалізація через cvxpy; перевірка feasibility на кожному кроці |
| 4 | Журналювання: статус розв'язку, значення цільової функції, обчислювальний час |
| 5 | Повертає першу складову оптимальної послідовності |

#### 3.2.7. `mpc_controller.py`

Інтегрує повний крок керування в порядку: отримання вимірювань → SVR-фільтрація → оновлення ковзного вікна → обчислення спільної матриці Грама → KRR-прогноз + GP-дисперсія → визначення режиму та `R(k)` → розв'язання QP → видача керуючого впливу.

### 3.3. Базові лінії

| Модуль | Опис |
|--------|------|
| `classic_mpc.py` | MPC з фіксованою `R₀` |
| `prototype_mpc.py` | MPC з адаптацією `R` за автокореляцією похибки прогнозу |

Базові лінії використовують ту саму модель об'єкта і той самий інтерфейс, що й основний регулятор.

### 4.1. Сценарії

| ID | Сценарій | Призначення |
|----|----------|-------------|
| EXP-1 | Штатний режим, номінальні умови, без збурень | Базова працездатність, відсутність погіршення проти базових ліній |

| EXP-4 | Ступінчасті збурення складу живлення | Якість перехідного процесу за адаптивної `R(k)` |
| EXP-5 | Абляція: повна схема vs без SVR vs із фіксованою `R` | Внесок кожного компонента окремо |
| EXP-6 | Спільна матриця Грама vs дві окремі інверсії | Виграш продуктивності |
| EXP-7 | Тривалий прогін зі змішаними збуреннями | Інтегральна оцінка в умовах, близьких до експлуатаційних |

### 4.2. Вимоги до проведення

| № | Вимога |
|---|--------|
| 1 | Кожен сценарій виконується для повної схеми + обох базових ліній на ідентичних реалізаціях збурень і шуму (один seed) |
| 2 | За наявності випадкових компонентів — серія `N ≥ 30` прогонів з різними seed; результат подається як середнє ± довірчий інтервал |
