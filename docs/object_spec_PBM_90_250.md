# Специфікація об'єкта керування
## Магнітний сепаратор ПБМ 90/250

**Призначення:** референсні дані для модуля `object_model/` згідно з ТЗ `technical_spec_dev.md`, розд. 2.
**Джерело:** ГОСТ 10512-78 «Сепараторы магнитные и электромагнитные. Технические условия» (зі Зміною № 5).
**Тип об'єкта:** ПБМ — магнітний барабанний сепаратор для мокрого збагачення сильномагнітних руд, з прямоточною ванною.

---

## 1. ВАЖЛИВЕ ЗАУВАЖЕННЯ ЩОДО ВИБОРУ ТИПОРОЗМІРУ

У ГОСТ 10512-78 (Зміна № 5, Таблиця 1) присутні **два стовпці «ПБМ 90/250»**:

| Варіант | Статус | Магнітна індукція на поверхні барабана |
|---------|--------|----------------------------------------|
| ПБМ 90/250* (зі зірочкою) | Застарілий, випуск припинено не пізніше 01.01.91 | 0,148 Тл |
| **ПБМ 90/250 (без зірочки)** | **Актуальний — використовувати цей** | **0,160 Тл** |

**Для проєкту використовуються параметри актуального ПБМ 90/250 (без зірочки).**

## 2А. ПАРАМЕТРИ ПУЛЬПИ (ГОСТ 10512-78, Таблиця 3, стор. 15)

ГОСТ нормує параметри пульпи окремо за **типом ванни**. ПБМ 90/250 у цьому проєкті — сепаратор **з прямоточною ванною** (тип без буквеного позначення виконання за п. 1.2 ГОСТ).

| Призначення пульпи | Вміст твердого продукту в пульпі, за масою | Густина пульпи | Вміст класу мінус 0,074 мм у твердому продукті |
|--------------------|-------------------------------------------|----------------|------------------------------------------------|
| Пульпа для ПБМ з полупротитечійною ванною | 27–30 % | 1,24–1,27 т/м³ | 90–95 % |
| Пульпа для ПБМ з протитечійною ванною | 49–53 % | 1,50–1,55 т/м³ | 50–55 % |
| **Пульпа для ПБМ з прямотечійною ванною** | **49–53 %** | **1,50–1,55 т/м³** | **19–22 %** |

**Для проєкту (прямотечійна ванна):** густина пульпи `ρ` = **1500–1550 кг/м³**.

## 3. ВІДОБРАЖЕННЯ ПАРАМЕТРІВ ГОСТ НА ЗМІННІ МОДЕЛІ

ТЗ розд. 2.1 визначає три керуючі впливи: `B` (магнітна індукція), `ρ` (густина пульпи), `Q` (продуктивність живлення). Прив'язка до ГОСТ:

| Змінна ТЗ | Параметр ГОСТ | Діапазон для моделі | Обґрунтування діапазону |
|-----------|---------------|---------------------|-------------------------|
| `Q` — продуктивність живлення | Таблиця 1, п. 1 | **105–160 т/год** | Прямо з ГОСТ для ПБМ 90/250 |
| `B` — магнітна індукція | Таблиця 1, п. 2 | **0,065–0,160 Тл** | Верхня межа — індукція на поверхні барабана (п. 2 ГОСТ); нижня — індукція на відстані 50 мм (п. 3 ГОСТ), як фізично досяжний мінімум у робочій зоні. Проміжні значення відповідають різному положенню матеріалу відносно барабана |
| `ρ` — густина пульпи | Таблиця 3 (прямотечійна ванна) | **1500–1550 кг/м³** | Прямо з ГОСТ для пульпи ПБМ з прямотечійною ванною |

**Зміна відносно ТЗ розд. 2.1:** початкові орієнтовні діапазони ТЗ (`B`: 0.05–0.15 Тл; `ρ`: 1100–1450 кг/м³; `Q`: 20–60 т/год) **замінюються** на паспортні/нормативні діапазони ПБМ 90/250 з цієї специфікації.

**Зауваження щодо діапазону `ρ`:** нормативний діапазон вузький (50 кг/м³, тобто ±1,6 % від центру). Для керуючого впливу MPC це обмежує «свободу» керування по цій змінній. Це **властивість об'єкта за ГОСТ, не помилка** — розробник має враховувати її при налаштуванні обмежень QP і не розширювати діапазон довільно. Якщо знадобиться ширший діапазон `ρ`, його джерелом має бути технологічний регламент конкретного ГЗК, а не довільне припущення.

## 4. ПАРАМЕТРИ, ВІДСУТНІ В ГОСТ 10512-78

ГОСТ 10512-78 нормує **конструктивні та паспортні** характеристики сепаратора і параметри пульпи, але **не описує технологічний процес збагачення** — тобто не містить:

| Відсутній параметр | Потрібен для | Джерело, яке треба знайти |
|--------------------|--------------|---------------------------|
| Залежності `βFe = f(B,ρ,Q,αFe,d)` | Статична модель об'єкта | Література зі збагачення магнетитових руд / дані ГЗК |
| Залежності `ε = f(B,ρ,Q,αFe,d)` | Статична модель об'єкта | Те саме |
| Сталі часу, транспортне запізнення | Динамічна модель об'єкта | Література з ідентифікації процесів магнітної сепарації / дані ГЗК |
| Діапазон масової частки заліза у живленні `αFe` | Генератор збурень | Дані конкретного ГЗК (для криворізьких руд — окреме джерело) |
| Рівень шуму вимірювань | Модель шуму | Характеристики промислових датчиків βFe, ε |

**Висновок:** ГОСТ 10512-78 закриває всі три керуючі впливи (`B`, `Q` — Таблиця 1; `ρ` — Таблиця 3) і всі конструктивні характеристики, але **технологічні залежності `βFe,ε=f(...)` та динамічні характеристики потребують окремих джерел**. Це не суперечить ТЗ — у ТЗ розд. 2.2.1 модель будується «на основі опублікованих залежностей», і ГОСТ є одним зі джерел, що покриває вхідні/вихідні діапазони, але не сам оператор процесу.

## 5. ВИМОГИ ДО ВИКОРИСТАННЯ У КОДІ

| № | Вимога |
|---|--------|
| 5.1 | Параметри розд. 2 і 2А заносяться в `object_model/object_config.yaml` з коментарем-джерелом: для конструктивних/паспортних — `# джерело: ГОСТ 10512-78, Таблица 1 (ред. Изм. №5), ПБМ 90/250`; для пульпи — `# джерело: ГОСТ 10512-78, Таблица 3, ПБМ з прямотечійною ванною` |
| 5.2 | Для кожного параметра з розд. 4 (відсутнього в ГОСТ) у конфігурації вказується власне джерело; параметри без підтвердженого джерела позначаються коментарем `# ПРИПУЩЕННЯ: обґрунтування` |
| 5.3 | Діапазони керуючих впливів `B` і `Q` у моделі не повинні виходити за межі розд. 3 цієї специфікації |
| 5.4 | Протокол валідації моделі (ТЗ розд. 2.2.6) перевіряє, зокрема, що номінальний режим роботи лежить у паспортних діапазонах ПБМ 90/250 |
| 5.5 | У зведеному протоколі (ТЗ розд. 7.8) тип об'єкта вказується як «ПБМ 90/250 за ГОСТ 10512-78» з посиланням на цю специфікацію |
