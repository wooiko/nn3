## 1. Статус моделі

Модель є **феноменологічною**: структура функцій обґрунтована фізикою процесу (баланс магнітної сили та сили Стокса) і якісними залежностями з літератури (`pbm_report_1`, `pbm_report_2`); числові коефіцієнти є вільними параметрами, що підлягають ідентифікації.

Модель **придатна** для:
- відносного порівняння регуляторів на ідентичному об'єкті (MIL-експерименти);
- демонстрації адаптивної логіки R(k) за наявності антагонізму βFe↔ε та нелінійності.

Модель **не є** кількісно валідованою щодо конкретного агрегату ГЗК — числові еталонні точки `(B,Q,ρ,αFe,βFe,ε)` для ПБМ 90/250 у відкритому доступі відсутні (`pbm_report_2`).

## 5. Коментарі по ключових перевірках

### 8.6 — ε(ρ): немонотонна з оптимумом
`g_ρ(ρ)` реалізована як гаусоподібна функція з максимумом у `ρ_opt = 1520` кг/м³. Оптимум знаходиться всередині ГОСТ-діапазону [1500, 1550] (idx_max = 8/19 ≈ 42% від початку діапазону). Це відповідає специфікації `static_model_spec.md` розд. 6.2: структура загальніша і покриває як немонотонний випадок (`pbm_report_2`), так і спадний (`pbm_report_1`).

### 8.7 — Антагонізм
Антагонізм βFe↔ε підтверджений конструктивно для всіх чотирьох аргументів. Зокрема:
- по **B**: ε зростає (насичення не досягнуте), βFe вже спадає після `B_opt_β = 0.12` Тл;
- по **Q**: ε спадає монотонно, βFe має слабкий максимум у `Q_opt_β = 115` т/год;
- по **ρ** та **αFe**: протилежні знаки похідних у відповідних ділянках.

### 8.8 — Взаємодія аргументів
Змішана похідна ∂²ε/∂B∂ρ = 1.77×10⁻² ≠ 0 підтверджує, що модель не зводиться до адитивної. Взаємодія закладена через `k_eff(B) × g_ρ(ρ)` у структурі ε.

### 8.10 — Номінальний режим
При B = 0.1125 Тл, Q = 132.5 т/год, ρ = 1525 кг/м³, αFe = 0.33:
- βFe = 61.80 % — відповідає орієнтирам `pbm_report_1` (ЦГОК 65–68.2 %, `[ЛІТ-ЯК]`) та `pbm_report_2` (65 %+);
- ε = 89.08 % — в діапазоні правдоподібного (90–95 % як орієнтир `[ЛІТ-ЯК]`).

## 6. Поведінка на межах (специфікація розд. 7.2)

Перевірка `test_boundary_modes_clip_warning`: при виході B за межу `B_max_dom`:
- модель **не аварійно завершується**;
- **виводиться `UserWarning`** з описом порушення;
- вхід **насичується (clip)** до межі домену;
- вихід залишається у фізично осмислених межах [0, 1].

## 8. Відкриті питання (не блокують, зафіксовані)

1. **`αFe` діапазон** — точне джерело діапазону [28, 38 %] для криворізьких магнетитових кварцитів відсутнє; позначено `[ASSUMPTION]` у конфігурації.
2. **`B_opt_β`** — специфікація дає 0.12 Тл, `pbm_report_1` — 0.15–0.18 Тл; розбіжність фіксована, уточнюється ідентифікацією.
3. **Числові коефіцієнти** — всі `[ASSUMPTION]` і `[LIT-QUAL]` підлягають ідентифікації за реальними виробничими або експериментальними даними.
