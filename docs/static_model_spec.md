# Специфікація модуля `static_model.py`
## Феноменологічна статична модель показників магнітної сепарації βFe, ε

**Призначення:** реалізація статичної моделі об'єкта для модуля `object_model/static_model.py` згідно з ТЗ `technical_spec_dev.md` (розд. 2.2.1).
**Об'єкт:** магнітний сепаратор ПБМ 90/250 з прямотечійною ванною.
**Підхід:** феноменологічна модель — структура задається фізикою процесу та якісними залежностями з літератури; числові коефіцієнти є **вільними параметрами ідентифікації** з початковими значеннями.
**Джерельна база:** ГОСТ 10512-78 (`object_spec_PBM_90_250.md`); звіти досліджень `pbm_report_1`, `pbm_report_2`.

---

## 1. ПРИНЦИПОВЕ ЗАУВАЖЕННЯ ПРО СТАТУС МОДЕЛІ

### 1.1. Що це за модель

Аналітичних формул `βFe, ε = f(B,Q,ρ)` з числовими коефіцієнтами для ПБМ 90/250 на магнетитових рудах у відкритому доступі **не існує** (підтверджено звітом `pbm_report_2`). Тому модель будується як **феноменологічна**:

- **структура функцій** — обґрунтована фізикою процесу (баланс магнітної сили та сили гідродинамічного опору) і якісними залежностями, узгоджено підтвердженими обома звітами;
- **числові коефіцієнти** — вільні параметри з початковими значеннями-припущеннями, винесені в конфігурацію, з маркуванням «підлягає ідентифікації».

### 1.2. Як модель використовується і чого від неї НЕ треба вимагати

| Модель ПРИДАТНА для | Модель НЕ ПРИДАТНА для |
|---------------------|------------------------|
| Відносного порівняння регуляторів на ідентичному об'єкті (запропонована схема vs базові лінії) | Прогнозу абсолютних значень βFe, ε конкретного агрегату |
| Демонстрації роботи адаптивної логіки R(k) за наявності антагонізму βFe↔ε, нелінійності, режимів з різною невизначеністю | Кількісної валідації проти паспортних показників ГЗК |
| Генерації даних для MIL-експериментів | Заміни натурних або виробничих даних |

**Це коректний підхід для MIL:** технічний результат у заявці доводиться як відносне покращення на однаковій для всіх регуляторів моделі об'єкта; абсолютна точність моделі для цього не критична — критична фізична правдоподібність і однаковість.

### 1.3. Вимога до документування статусу

У зведеному протоколі (ТЗ розд. 7.8) і скрізь, де модель згадується, її статус формулюється чесно: **«феноменологічна модель, структурно обґрунтована фізикою процесу та якісними залежностями з літератури, з коефіцієнтами, що підлягають ідентифікації»**. Не подавати як валідовану кількісну модель конкретного агрегату.

## 2. ФІЗИЧНИЙ БАЗИС (обґрунтування структури)

Структура моделі випливає з балансу сил, що діють на мінеральну частинку в робочій зоні (звіт `pbm_report_1`, теоретична частина; класична теорія магнітної сепарації):

| Сила | Залежить від | Наслідок для моделі |
|------|--------------|---------------------|
| Магнітна сила `F_mag` | індукції `B`, градієнта поля, магнітної сприйнятливості, об'єму частинки | Зростання `B` → більше захоплення магнітних частинок → зростає `ε`; за межею — захоплення зростків → падає `βFe` |
| Гідродинамічний опір `F_drag` (закон Стокса) | в'язкості пульпи, швидкості потоку (∝ `Q`) | Зростання `Q` → зростає `F_drag` → змивання частинок у хвости → падає `ε` |
| В'язкість пульпи | густини пульпи `ρ` (нелінійно зростає з вмістом твердого) | Зростання `ρ` → зростає в'язкість → погіршується сепарація дрібних класів; механічне затиснення породи → падає `βFe` |

Ключові структурні наслідки:
1. `ε` від `B` — насичувальна залежність (`F_mag` зростає, доки майже всі магнітні частинки не захоплені);
2. `ε` від `Q` — спадна (зростання `F_drag`);
3. `βFe` від `B` — з максимумом (спочатку росте якість, потім захоплення зростків);
4. обидва показники погіршуються при надмірному `ρ`;
5. **антагонізм** `βFe ↔ ε` — фактори, що підвищують вилучення, знижують якість;
6. **взаємодія** аргументів — вплив `B` залежить від `ρ`; вплив `Q` залежить від `αFe`.

## 3. ЯКІСНІ ЗАЛЕЖНОСТІ — ЗВЕДЕННЯ ДВОХ ЗВІТІВ

Обидва звіти узгоджено підтверджують характер залежностей (розбіжності — лише в наявності/відсутності числових коефіцієнтів, не в характері).

| Залежність | Характер | Узгодженість звітів |
|-----------|----------|---------------------|
| `βFe(B)` | Зростає до насичення, далі можливий спад (захоплення зростків, флокуляція) | Обидва звіти; `report_2` уточнює — для LIMS (B ≤ 0,25 Тл) спад маловиражений |
| `ε(B)` | Монотонно зростає з насиченням; нижче B ≈ 0,10–0,12 Тл різко падає | Обидва звіти |
| `βFe(Q)` | Слабкий максимум (помірне Q покращує промивку зростків), далі спад | Обидва звіти; **суперечлива** — див. розд. 6 |
| `ε(Q)` | Монотонно спадає; за межею ~150–160 т/год — різкий спад | Обидва звіти |
| `βFe(ρ)` | Спадає зі зростанням `ρ` (в'язкість, затиснення породи) | Обидва звіти |
| `ε(ρ)` | Немонотонна: за низького `ρ` слабка флокуляція → нижче `ε`; оптимум у середньому діапазоні; за надмірного `ρ` — спад | `report_2` (детальніше); `report_1` дає переважно спадну гілку |
| `βFe(αFe)` | Монотонно зростає | `report_1`; `report_2` — якісно |
| `ε(αFe)` | Може мати негативний тренд за фіксованого `Q` (перевантаження магнітної ємності барабана) | Обидва звіти |

**Структурний висновок `ε(ρ)`:** модель має відтворювати немонотонність — оптимум у середині діапазону. Це важливо: проста спадна функція втратить фізичний ефект.

## 4. СТРУКТУРА МОДЕЛІ

### 4.1. Загальна форма

```
βFe = βFe_base(B, Q, ρ, αFe)
ε   = ε_base(B, Q, ρ, αFe)
```

Обидві функції — детерміновані, неперервні, диференційовні на області визначення (розд. 7). Шум і динаміка **не входять** у цей модуль (їх додають `disturbances.py` і `dynamic_model.py` відповідно — ТЗ розд. 3.1).

### 4.2. Модель `ε` — насичувальна, на базі Rayner–Napier-Munn

Структурна основа — модель першого порядку флокуляції `ε = 1 − exp(−k·τ)` (Rayner & Napier-Munn, 2003; звіт `pbm_report_2`, блок 3.2.2). Адаптована форма:

```
ε = ε_max · (1 − exp(−k_eff · τ)) · g_ρ(ρ) · g_α(αFe)

де:
  τ      = τ_ref · (Q_ref / Q)              # час перебування, спадає з Q
  k_eff  = k_0 · sat_B(B)                   # ефективна швидкість захоплення
  sat_B(B) = 1 − exp(−(B − B_min) / B_scale) для B > B_min, інакше 0
  g_ρ(ρ) = дзвоноподібна функція з максимумом у ρ_opt (немонотонність!)
  g_α(αFe) = 1 − c_α · max(0, αFe − αFe_ref) # перевантаження магнітної ємності
```

`g_ρ(ρ)` — реалізувати як гаусоподібну або параболічну функцію з максимумом у `ρ_opt`, нормовану так, що `g_ρ(ρ_opt) = 1`.

### 4.3. Модель `βFe` — з максимумом по B, штрафами по Q і ρ

```
βFe = βFe_floor + (βFe_ceil − βFe_floor) · h_B(B) · p_Q(Q) · p_ρ(ρ) + c_β · (αFe − αFe_ref)

де:
  h_B(B) = функція з максимумом у B_opt_β:
           зростає до B_opt_β, далі повільно спадає (захоплення зростків)
  p_Q(Q) = функція з пологим максимумом у Q_opt_β (слабкий максимум промивки)
  p_ρ(ρ) = монотонно спадна за ρ (затиснення породи, в'язкість)
  c_β    = коефіцієнт впливу αFe (лінійний доданок)
```

`h_B(B)` — реалізувати як добуток насичувальної та повільно-спадної компоненти, або як асиметричну дзвоноподібну функцію.

### 4.4. Забезпечення антагонізму βFe↔ε

Антагонізм виникає **конструктивно**, бо одні й ті самі аргументи входять у `βFe` і `ε` з протилежним знаком впливу за межами оптимумів:
- зростання `B` понад `B_opt_β`: `ε` ще зростає (насичення не досягнуте) — `βFe` вже спадає;
- зростання `ρ`: `βFe` монотонно спадає — `ε` спадає лише за межами `ρ_opt`, у нижній частині діапазону навіть зростає.

**Вимога:** протокол валідації (розд. 8) має явно перевірити наявність антагонізму — існування області, де `∂βFe/∂x` і `∂ε/∂x` мають різні знаки.

### 4.5. Забезпечення взаємодії аргументів

Взаємодія закладається через `k_eff = k_0 · sat_B(B)` у поєднанні з `g_ρ(ρ)`: вплив `B` на `ε` промодульований рівнем `ρ`. Аналогічно `g_α(αFe)` модулює вплив `Q` через `τ`. Адитивна модель без перехресних членів **не допускається** — обидва звіти підтверджують наявність взаємодії.

## 6. СУПЕРЕЧНІСТЬ МІЖ ДЖЕРЕЛАМИ — ЯК ВИРІШЕНО

### 6.1. `βFe(Q)` — монотонний спад чи максимум?

| Варіант | Джерело |
|---------|---------|
| Монотонний спад якості зі зростанням `Q` (турбулентність) | частина джерел `report_1`, `report_2` |
| Помірне зростання `Q` покращує селективність (промивка зростків) → слабкий максимум | технологічні регламенти, `report_1` |

**Рішення для моделі:** реалізувати `p_Q(Q)` як функцію зі **слабким, пологим максимумом** у `Q_opt_β ≈ 115` т/год. Початкове значення `Q_width_β = 40` робить максимум настільки пологим, що в робочому діапазоні поведінка близька до майже-монотонної — це покриває обидва варіанти. При ідентифікації `Q_width_β → ∞` зведе залежність до монотонної, якщо дані цього вимагатимуть. Тобто структура **не нав'язує** жодного з варіантів — вибір визначиться калібруванням.

### 6.2. `ε(ρ)` — спадна чи з оптимумом?

`report_1` дає переважно спадну гілку, `report_2` — немонотонну з оптимумом. **Рішення:** реалізувати `g_ρ(ρ)` як дзвоноподібну з максимумом `ρ_opt`. Якщо ідентифікація покаже, що в робочому ГОСТ-діапазоні (1500–1550, вузький) фактично спостерігається лише спадна гілка — це вийде природно при `ρ_opt ≤ 1500`. Структура загальніша і покриває обидва варіанти.

### 6.3. Принцип

Де джерела суперечать — структура моделі обирається **найбільш загальною** з тих, що здатна звестись до кожного з варіантів зміною коефіцієнтів. Остаточний вибір — за ідентифікацією, не за цією специфікацією.

## 8. ПРОТОКОЛ ВАЛІДАЦІЇ МОДЕЛІ (для `validation_protocol.py`)

Реалізує вимогу ТЗ розд. 2.2.6. Перевірки:

| № | Перевірка | Критерій проходження |
|---|-----------|----------------------|
| 8.1 | Діапазони виходів | `βFe`, `ε` лежать у фізично правдоподібних межах на всій сітці області визначення |
| 8.2 | `ε(B)` монотонно зростає | `∂ε/∂B ≥ 0` на всій області визначення |
| 8.3 | `ε(Q)` монотонно спадає | `∂ε/∂Q ≤ 0` на всій області визначення |
| 8.4 | `βFe(B)` має максимум | існує `B_opt_β` всередині або біля діапазону, де `∂βFe/∂B` змінює знак, АБО монотонність із пологим характером (залежно від калібрування) |
| 8.5 | `βFe(ρ)` спадна | `∂βFe/∂ρ ≤ 0` на всій області визначення |
| 8.6 | `ε(ρ)` має оптимум або спадна | поведінка відповідає `g_ρ` з заданим `ρ_opt` |
| 8.7 | **Антагонізм βFe↔ε** | існує хоча б один аргумент `x` і область значень, де `sign(∂βFe/∂x) ≠ sign(∂ε/∂x)` |
| 8.8 | **Взаємодія аргументів** | `∂²ε/∂B∂ρ ≠ 0` (модель не зводиться до адитивної) |
| 8.9 | Неперервність | відсутність розривів на стиках кусково-визначених ділянок |
| 8.10 | Узгодженість з ГОСТ | номінальний режим (центр області визначення) дає `βFe`, `ε` у правдоподібних для ПБМ 90/250 межах |

Протокол валідації запускається перед формуванням будь-яких результатів (ТЗ розд. 6).

## 9. ДАНІ ДЛЯ ТЕСТІВ І ВІДКРИТІ ПИТАННЯ

### 9.1. Референтні точки — статус

Звіт `pbm_report_2` прямо встановив: числові точки `(B,Q,ρ,αFe,βFe,ε)` для ПБМ 90/250 на криворізьких магнетитових рудах **у відкритому доступі відсутні**. Точки, наведені у `pbm_report_1` як «дані для верифікації», за простежуваністю джерел є **синтезом/інтерполяцією виконавця**, а не вимірюваннями — їх не можна використовувати як еталон валідації.

### 9.2. Як тестувати модель за відсутності еталонних точок

| Рівень | Що перевіряти |
|--------|---------------|
| Модульні тести | **Якісні властивості**, не абсолютні значення: монотонності (8.2, 8.3, 8.5), наявність максимумів (8.4), антагонізм (8.7), взаємодія (8.8), неперервність (8.9), межі виходів (8.3) |
| Тести узгодженості | Номінальний режим дає правдоподібні значення; зміна кожного аргументу дає очікуваний напрямок зміни виходів |
| Регресійні тести | Зафіксувати поточний вихід моделі на опорній сітці як еталон; зміна коду не повинна його непомітно зсувати (порівняння структури, не «правильності») |

Орієнтири правдоподібності (НЕ еталони, а діапазони здорового глузду):
- `βFe` у номінальному режимі — близько 63–66 %;
- `ε` у номінальному режимі — високе, близько 90–95 %;
- джерело орієнтирів: `pbm_report_1` (ЦГОК 65–68,2 %), `pbm_report_2` (Eriez 65 %+), маркувати як `[ЛІТ-ЯК]`.

### 9.3. Відкриті питання (не блокують розробку, фіксуються для подальшого)

1. Діапазон `αFe` для криворізьких магнетитових кварцитів — потребує джерела (технологічний регламент ГЗК).
2. Числові коефіцієнти всіх функцій — підлягають ідентифікації за реальними даними, коли/якщо вони з'являться.
3. Точки `B_opt_β`, `ρ_opt`, поріг `B_min` — звіти дають розбіжні орієнтири; уточнюються ідентифікацією.

### 9.4. Точка розширення

Модель проєктується так, щоб поява реальних даних (виробничих або експериментальних) дозволяла **калібрування через `object_config.yaml` без зміни коду**. Окрема функція/скрипт ідентифікації коефіцієнтів — бажаний, але не обов'язковий компонент; як мінімум структура коду не повинна перешкоджати такому калібруванню.
